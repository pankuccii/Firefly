Good to know

A few answers.

Can I use Firefly wirelessly?

Yes, on supported configurations. Pair and trust the iPhone over USB first, then enable “Show this iPhone when on Wi-Fi” in Finder. Wireless availability and refresh timing can vary with iOS and network conditions.

Which Mac can run Firefly?

The current beta targets Apple Silicon Macs and macOS 27. Check each release for its requirements.

Is the current beta notarized?

Not yet. The v0.1.7 build is locally signed and has not received Apple notarization. Download only from the project's GitHub releases and avoid disabling macOS security protections.

Is Firefly Pro available?

No. It is a possible future one-time upgrade. The current Firefly beta is free.
