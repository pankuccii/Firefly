Frequently asked

Good to know.

Does Firefly work without a cable?

On supported configurations, yes. First pair your iPhone by USB, then enable Finder's “Show this iPhone when on Wi-Fi” option. Connectivity and refresh timing vary with your network and iOS behavior.

What Mac do I need?

The current project targets Apple Silicon and macOS 27. Check each release for its exact system requirements.

Is Firefly notarized by Apple?

The current v0.1.7 beta is locally signed and has not been notarized. Only download from the official GitHub release and don't disable macOS security protections.

Do I need an account?

No mandatory account or cloud service is required for Firefly's core local battery monitoring.

Can I buy Firefly Pro?

Not yet. Firefly Pro is a possible future upgrade. The beta is available free of charge.
