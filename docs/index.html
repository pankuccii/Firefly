Good to know

A few quick answers.

Can Firefly work without a cable?

Yes, on supported configurations. First pair and trust the iPhone using USB, then enable “Show this iPhone when on Wi-Fi” in Finder. Wireless availability can vary depending on iOS behavior, network conditions, and pairing.

Which Mac do I need?

The current project documents Apple Silicon and macOS 27 as its target. Check the release notes for the exact requirements of each build.

Why does the battery sometimes stop updating?

Wireless availability can change when the iPhone locks, sleeps, or leaves the network. Firefly displays the most recent successful update so you know how fresh the reading is.

Is the beta notarized by Apple?

Not yet. The currently published v0.1.7 beta is locally signed and has no Apple notarization. Only download from the project's official GitHub releases and evaluate macOS security warnings carefully.

Do I need an account or cloud subscription?

No. Firefly's core battery monitoring is designed to work locally without a mandatory account or cloud service.

Can I buy Firefly Pro now?

Not yet. Firefly Pro and its pricing are proposals for future development. The currently available release is a free beta.
