See your iPhone battery over cellular data

When the iPhone and the Mac are not on the same network, Firefly can read the last battery report from an iCloud Drive file you choose. Both devices need access to the same iCloud Drive. In the iPhone settings, allow iCloud Drive to use cellular data.

Set up once on the iPhone

  1. Create a new shortcut in the Shortcuts app. Name it Firefly battery report.
  2. Add the Get Battery Level action (on some versions Get Battery Status → Battery Level). Choose a result that is a number from 0 to 100.
  3. Add Current Date and then Format Date. Choose the ISO 8601 format, including the time and the time zone. If needed, use the custom format yyyy-MM-dd'T'HH:mm:ssXXX.
  4. Add two lines to a Text action. Put the battery level on the first line with the variable picker, and the formatted date on the second line. Do not add a percent sign, a label or quotation marks.
  5. Use Set Name to name the text Firefly.txt. In Save File, choose the Shortcuts folder in iCloud Drive. Turn off Ask Where to Save and turn on overwriting the existing file. Run the shortcut once.

Link it on the Mac

Go to Firefly → Settings → Battery reports over cellular → Select report file and choose the same Firefly.txt file. While a local reading is available, USB or Wi-Fi takes priority. When the local connection drops, a newer iCloud report appears in the panel with its measurement time. A report older than five minutes is not shown as a current percentage in the menu bar.

Update automatically

In Shortcuts → Automation, add Run Shortcut → Firefly battery report for the charger being connected or disconnected, a battery level being crossed, or a time of day. Choose “Run Immediately” where available. New data arrives once the shortcut has run and the file has synced. The charging state is not inferred from the file. You can remove the link in Firefly's settings.
